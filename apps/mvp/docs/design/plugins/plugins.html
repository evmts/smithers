The decision in five rules

Thirteen rules in the decision; these five carry it.

  1. A small core; everything else is a plugin.16 named primitives. Our features use the same interface as anyone's, and the core names no plugin outside its built-in list.
  2. One manifest, in the SDK we have.plugin.json, decoded by Plugin.Manifest in @smthrs/plugin, with the host contract PluginHost beside it. No new package.
  3. Plugins act only through flows, and every dispatch carries who asked.The server mints a credential per run naming the person, the agent or plugin acting for them, and its ceiling. Flows can run over other flows.
  4. Everything not compiled in runs in a sandbox.Flow code in the QuickJS realm; React apps in a sandboxed frame; machine work in a container. Every plugin and the agent can ship a React app.
  5. People act; plugins and agents never act as them.Person-only routes refuse any agent or plugin credential, and the host draws every person-only button and key itself. A merge activates a plugin; an Admin grants each secret to each plugin.

Core versus plugins

Plugins sit on one interface. The interface sits on the core. Nothing reaches past it.

Contribution points

Each lands with its first consumer. Until then the host refuses it by name, so nothing half-loads.

views

A view in the chat shell, inline or full screen, with the queries it reads and the events it binds to flows.

any · slice 1
slots

An entry in a named place: shell.nav, shell.header, repo.tabs, branch.pane, item.pane.

any · slice 1
commands

A flow, with fixed args, as a slash command and a palette entry.

any · slice 1
keybindings

A key and a when: exactly one command or one declared view event.

any · slice 1
triggers

An event, cron, webhook, or other runs' events with over: flows over flows.

built-in · repository · slice 2
hooks · taps

A seam a plugin owns, and a flow or value on it. Each acting tap is a durable child run.

as the hook allows · slice 4
records

Small JSON records only the plugin's flows write, synced by an authorized shape.

any · slice 4
flows · owns

The flows a plugin owns: its own folder, or .smithers/flows/<name> for a repository plugin. One owner per flow.

slice 5 for repositories
settings

A person or repository setting with a JSON Schema. A secret field is refused.

any · slice 5
modelRoles

A named model use; Admins map it; calls go through ModelStep within budgets.

Never, for any plugin, app or agent
  • act with your session: they hold a run credential, and person-only routes refuse it
  • answer, approve, merge or pre-approve for you
  • change roles, settings, protection or secrets
  • start or override a system flow
  • read a secret's value, or use another plugin's grant
  • run in the app's realm without being compiled in
  • ask you for a password or token inline
  • draw a person-only button: the host draws those

  3. 2

    Durable asks and flows over flows

    smthrs ask with its own deadline, so the lead and curator ask you through Smithers. Later and undo, never past a deadline. Priority. Run-event triggers, with the curator over todo runs as the first flow over flows.

  4. 3

    React apps in sandboxed frames, and the parity gate

    Gated first: a host-drawn label on every frame; no inline credential prompts; password inputs refused; a views-origin wrapper with frame-src 'self' and a zero-foreign-requests test; src/pwa.ts:34 narrowed. Then the frame, its bridge and the agent's ui/app cards. Gate: the same queue ships as a framed app, and 2 on the host's strip still answers.

  5. 4

    Review plugins, hooks and records

    review-media (a chapter timeline) and review-code (slices pinned to a commit) add item kinds through the first hook. The maintainer queue and GIF pages retire.

  6. 5

    Repository plugins and the realm flow host

    Hand-edited personal flows run in QuickJS. Installation snapshots, owns, preview, and the work board: merge it and the Work tab appears with no deploy.

  7. 6

    Seams repositories can tap, and secret grants (M-47)

    Triage, notifications, issue transitions and merge rules take repository taps with their failure rules. Per-plugin secret grants, switched on only when their tests pass.

  8. 7

    Convert web, jev, runs, flows, repo, home, issues, triage, notifications, todos, branch, then agent. Personal plugins, vendored npm plugins, and the lossless pack.json migration.
