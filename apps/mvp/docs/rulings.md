## 3. Durable flows

Will, 2026-10-19 18:13: "This is important our entire application will be built on top of durable workflows. We are going to treat every action the agent does as a durable workflow. There should be no thinking about retries and stuff it should just be built into the durable model." 18:12: "whatever abstraction we have that is doing the model call should be durable by default just like all of smithers because the base layer is durable flows and we build everything else on top of it".
