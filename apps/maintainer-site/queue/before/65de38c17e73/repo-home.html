VibeLang

Reliable TypeScript for the AI era, built on Effect.

A simple, readable syntax for Effect that compiles to TypeScript, with first-class access to the TypeScript ecosystem.

Get started Cheat sheet Docs
$npm create vibelang@latest my-app
MITLicense
Effect 4Runtime
macOS · Linux · Windowsarm64 and x64
0.0.1Latest on npm

Why VibeLang

Every function is an Effect

A call runs where it stands; no `yield*`, no generators.

Typed errors

`error NotFound { id }` and `User!NotFound` in the signature.

Services and layers

`service`, `provide` and `Layer` as language.

Concurrency

`await.all`, `await.race`, `fork` and `join`.

Your editor knows it

Diagnostics, hovers and completions from the compiler.

TypeScript interop

Checks `.vibe` and `.ts` together; emits JavaScript and types.

Effect

Build production-ready applications in TypeScript.

Typed errors, dependency injection, structured concurrency, retries, tracing and schemas in one library with zero dependencies.

Get started Playground Discord
$npm install effect
MITLicense
0Dependencies
TypeScript 5.9+Strict mode
Node · Bun · Denoand browsers

Why Effect

Typed errors

Every failure is in the type, so the compiler lists what you haven't handled.

Dependency injection

Services and layers, checked at compile time, swapped in tests.

Structured concurrency

Fibers that cancel cleanly, with no leaked work.

Retries and scheduling

Backoff, jitter and timeouts as values you compose.

Built-in tracing

Spans and metrics with OpenTelemetry, no extra code.

Schema

One definition to validate, decode, encode and document data.

Who is who

  • Maintainer: a Maintainer or an Admin.
  • Contributor: anyone signed in with a role on the repository, Guest included; or anyone, when the repository opts in.
  • Visitor: everyone else, signed out included.
  • ChatApi decides the audience from the session and never sends a curated section above it. Each live block's rows come from its own shape, which checks the role again.

New branch

  • An action block: a primary button that runs one flow, branch.new, and its key, B, while you aren't typing.
  • It makes the branch at the default branch's head on the repository's forge and opens its workspace: conversation, terminal and views (0013).
  • The same branch/create flow is /branch.new and the agent's.
  • Branches shows who is on which branch; it needs a branches shape and is not built yet.
