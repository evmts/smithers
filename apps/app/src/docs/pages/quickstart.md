Find an action in the app. You do not need the CLI to use the app.

## Open the command list

1. Open **Chat** with Command-K on macOS or Control-K on Windows and Linux.
2. Enter `/chat.commands` and press Enter.
3. Read the commands and their descriptions in the conversation.

See [Flows reference](flows.md#find-a-command) to filter the command menu.

For installation and setup, use the [install page](https://smithers.sh/docs/installation/).
